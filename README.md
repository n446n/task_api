# タスク管理API

日々の定型業務チェックリストを管理するための、タスク管理APIです。
FastAPI と SQLite で作っています。

## 作った理由

時間ごとの業務が複雑なため整理とPython,API学習を兼ねて作りました。

## 使っている技術

- Python 3
- FastAPI
- SQLite（標準ライブラリの `sqlite3`）
- Pydantic（リクエストの形の定義）

## 動かし方

```bash
pip install fastapi uvicorn
python -m uvicorn task_api_public:app --reload
```

ブラウザで http://127.0.0.1:8000/docs を開くと、すべての機能を画面から試せます。

初回起動時に `tasks.db` が自動で作られ、ダミーのタスク26件が登録されます。

## 機能一覧

| 機能 | メソッド | URL |
|---|---|---|
| タスク一覧 | GET | `/tasks` |
| 時間で絞り込み | GET | `/tasks?time=11:30` |
| タスク追加 | POST | `/tasks` |
| タスク1件取得 | GET | `/tasks/{id}` |
| 完了にする | PUT | `/tasks/{id}/done` |
| 完了を取り消す | PUT | `/tasks/{id}/undo` |
| 全タスクの完了をリセット | PUT | `/tasks/reset` |
| タスク削除 | DELETE | `/tasks/{id}/del` |

存在しない id を指定した場合は、404 とメッセージを返します。

### タスク追加のリクエスト例

```json
{
  "title": "確認A",
  "time": "08:00"
}
```

### 全タスクの完了をリセット

1日の終わりに、すべてのタスクを未完了に戻すための機能です。
何件リセットしたかをメッセージで返します。

```json
{
  "message": "26件のタスクを未完了にしました"
}
```

## 工夫した点

- データは SQLite に保存するので、サーバーを再起動しても残ります
- SQL には `?` のプレースホルダを使い、値を直接文字列に埋め込まないようにしました
- 存在しない id への操作は、`HTTPException` で 404 を返すようにしました
- 完了・取り消し・削除は、`rowcount` で「実際に対象があったか」を確認しています
- 時間の絞り込みは、クエリパラメータ（`?time=`）を省略可能にして、1つの入口で「全件」と「絞り込み」を両立しました
